# 澳大利亚签证指南 · 材料清单与风险自测（Australia Visa Guide）

> 面向客户的一站式赴澳签证科普页面：**风险自测 + 签证简介 + 材料清单 + 出签贴士**，三分钟完成从"了解"到"自测"的全流程。

## ✨ 页面功能（四个选项卡）

**🎯 风险自测（默认打开）**
- 7 道选择题（目的 / 婚姻 / 同行人 / 出生地 / 出境记录 / 职业 / 资产区间），约 30 秒完成
- 实时评分（满分 10 分）+ 三档结果：🟢 把握较高 / 🟡 建议补强 / 🔴 风险较高
- 五维得分可视化 + 个性化提升建议（客户友好语气）
- 户籍警示：福建 / 江西 / 海南 / 青海出生申请人显示官方分省拒签率提示（内政部 FOI 数据）
- 纯前端计算，数据不上传

**📖 签证简介**
- 600 类别访客签证科普：电子签证 / 有效期 / 停留期 / 办理周期 / 75 岁以上特别要求
- 旅游 / 探亲 / 商务三种出行目的对比卡片
- 常见问题 FAQ（折叠展开）：护照邮寄、白本申请、拒签史、保险、澳新联游
- 🇳🇿 新西兰 ETA 新政提示（政策期至 2026 年 11 月）

**📋 材料清单（2026.07 最新版）**
- 五大分组 26 项材料：个人资料 / 资金证明 / 工作证明（按身份）/ 行程证明（按目的）/ 特殊情况（拒签史、未成年人、75 岁以上）
- 每项材料可点击打勾记录，自动计算备料进度，进度保存在本地（localStorage）
- 关键材料带醒目标签（必须提供 / 如有请提供 / 仅新西兰需提供）
- 「个人资料表」支持**一键下载 Word 模板**填写（`au-nz-visa-application-form.doc`，随仓库一起部署），后续将接入金数据在线填写

**📌 出签贴士**
- 置顶红色警戒卡：未成年人与父母一方（或其他人）出行时，领馆会致电**不同行的父母**核实——没接到或拒接电话**将被拒签**
- 澳新高效出签注意事项 5 条：电话畅通 / 资料扫描 / 出入境记录 / 流水账单调查 / 随行同意书
- 🚩 拒签红旗自检 8 项：临时大额转入 / 收入口径不一致 / 拒签史未申报 / 在澳伴侣或等待永居 / 行程模糊 / 电调准备不足 / 收入偏低 / 带娃条件偏弱——勾选即显示针对性建议（不计入评分）
- 递交前自查清单 8 项，逐条对照避免细节疏忽
- 📊 拒签数据与拒签后果（官方口径）：600.211 条款科普、中国籍平均拒签率 14.6%、高拒签省份前五、PIC 4020 诚信条款、程序性拒签期限、子女连带被拒、再申请策略

## 🧮 自测评分口径

与 100 例真实案例（2024.12–2025.09）回测验证一致：

| 维度 | 规则 |
|---|---|
| 经济能力 | ≥50万 +3 ｜ 10–50万 +2 ｜ 5–10万 +1 ｜ ＜5万 0 |
| 出境记录 | 优秀 +2 ｜ 良好 +1 ｜ 一般 / 无记录 0 |
| 职业属性 | 稳定职业 +2 ｜ 受薪职业 +1 ｜ 灵活就业 0 |
| 出行目的 | 旅游 / 探亲 +1 ｜ 商务 -1 |
| 回国约束力 | 已婚或有同行人 +1 ｜ 上海 +1 ｜ 黑吉辽 -1（下限 -1） |

判定：≥6 🟢 ｜ 4–5 🟡 ｜ ≤3 🔴

## 🔧 技术特点

- **单文件零依赖**：`index.html` 不依赖任何 CDN / 外部库，离线可用，国内外访问稳定
- **移动端优先**：客户手机扫码即可使用，备料进度本地保存
- **对外合规**：不展示内部业务数据，免责声明醒目，页脚预留品牌/二维码占位

## 🚀 使用

浏览器直接打开 `index.html`，或访问 GitHub Pages 在线地址。
